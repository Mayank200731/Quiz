# Quiz App

A lightweight and interactive quiz application built with HTML, CSS, and JavaScript. The app presents a series of questions, tracks the user's score, and provides instant feedback at the end.

## Live Demo

Visit the working app here:

https://quiz-iota-eosin.vercel.app/

## Features

- Multiple-choice quiz questions
- Score tracking as the user answers
- Instant result summary at the end of the quiz
- Clean and responsive interface
- Simple front-end implementation with no heavy dependencies

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Mayank200731/Quiz.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Quiz
   ```
3. Open `index.html` in your browser, or run a local web server:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000` in your browser.

## Purpose

This project is designed to be a simple quiz app for practicing front-end development fundamentals, including DOM manipulation, dynamic content rendering, and responsive UI design.
